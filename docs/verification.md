## Browser check before approving a release

Open both `index.html` and `dist/acronis-infographic-studio.html`. Compare with `standalone-v20.html`. Exercise all twelve examples and an imported Figma SVG; edit short/long live-text labels; replace an icon; switch themes; preview each style on hover/click/keyboard; open/close Fine Tune repeatedly; adjust an object; save/load JSON; export all six formats; cancel a raster export; enable reduced motion. Check static backgrounds, exact reset, consistent frame size and standalone HTML with the editor closed.

Animation control audit: all six styles scale their complete schedules, callbacks, pauses and hover playback across the 300–5000 ms range. Intensity controls reveal travel, construction scale, connected-element scale, Flow packet size, Scan identification focus and Magnet glow. Main slider changes replay immediately and keep numeric readouts synchronized. Intensity edits preserve separately tuned beat durations. Per-object controls inherit the main settings while using the selected style; static and reduced-motion controls are disabled. Native Chrome checks covered 252 timing cases and 168 intensity cases across the 12 templates plus network fixtures, with matching editor, capture and embedded HTML export timing.

Flow/Scan differentiation: Flow preserves the complete network and all labels throughout transmission, moves one signal at a time, and activates each destination without an opacity reveal. Scan uses one linear root-space beam, clipped node discovery at the beam position, leader extension at the same physical speed, and immediate label fade after line completion. Native Chrome checks covered 180 combinations of templates/fixtures, light/dark themes and duration endpoints; other four styles were compared against their previous frames and remained unchanged. Both hover previews and embedded HTML exports were verified, along with existing slider behavior and capture timing.

Direct selection workflow: the separate Apply Animation action is removed. Selecting a style applies it and starts preview immediately, including selections made while fonts/engine initialize; startup preserves the latest selection. Active cards stay synchronized with export settings. Duration and Intensity replay immediately. Library/import changes automatically prepare the selected style, and saved projects no longer require an apply step. Existing trigger preferences and object tuning are retained. Flow handoffs now have no per-node pauses and follow traversed paths between branches instead of jumping; the thumbnail demonstrates the same continuous journey in 2.4 seconds at default duration. Scan retains its invisible constant-speed discovery driver and immediate leader-to-label handoff.

UI hierarchy refinement: the ANIMATION heading leads directly into the cards, with concise descriptions and a selected checkmark, inset accent border and tint. The redundant active-status text is removed. Advanced Settings opens the existing fine-tuning drawer through a secondary text action. A visible Edit labels & icons CTA opens a native modal editor with focus on the first label, native keyboard focus containment/Escape handling, retained label/icon controls and one scrolling content area. Browser checks verified content editing, icon replacement access, advanced settings and direct export in the app and production bundle. Desktop and narrow viewport dimensions were inspected; application structure, branding and animation runtimes remain unchanged.
