## Export performance and feedback refinement

Animated SVG is now the first export option, marked Recommended, and receives focus when the export menu opens. It retains embedded Acronis Cyber typography and vector geometry. Sampling caches the SVG node list, omits repeated completed-state samples, and compresses unchanged keyframe runs without changing their timestamps. Non-holding custom timelines retain their complete loop samples.

GIF color quantization and LZW encoding run in a cancellable Blob worker, supported by both the modular app and the self-contained distribution. The adaptive palette now uses perceptual splitting and two centroid-refinement passes. Existing high-resolution supersampling and stable ordered dithering are retained. Nine palette samples are reused during output rendering; they are not rendered again. Opaque GIF frames encode only changed rectangles, and identical indexed frames merge their delays. GIF and APNG both replace the 0.9-second completed hold with one delayed frame, keeping moving content sampled at 30 fps and preserving total duration.

Progress includes preparation, sampling, rendering, encoding and finalization, with a progress bar, elapsed seconds, and persistent feedback on the Export button when the menu is closed. Cancel terminates the GIF worker promptly. Each export records its format, elapsed duration, success and cancellation in the bounded in-memory `exportTimings` array. No telemetry is sent. Completed jobs display their generation duration.

Native headless Chrome benchmark, same default-duration Connections diagram, 1920 × 1077 animation output, total playback 4.5 seconds. Values include export orchestration and download preparation; machine-dependent timings are not service guarantees:

## Global Motion Presets

The main animation controls now offer Subtle (recommended), Balanced and Dynamic above the editable Duration and Intensity sliders. Subtle uses 800 ms / intensity 2; Balanced retains the previous 1200 ms / intensity 3; Dynamic uses 1800 ms / intensity 7. Presets update every global story beat, hover-preview timing and emphasis, inherited element controls, and animation captures through the existing shared settings pipeline. Animation-family storytelling and explicit element overrides are retained.

Manual slider edits derive a Custom state when their values differ from all three presets. Set as Default saves either a named preset or custom values in versioned browser-local storage. Fresh examples and SVG imports apply that preference; loading an existing JSON project retains its saved values and does not overwrite the preference. New projects use Subtle when no valid preference is available. A bounded, validated schema prevents malformed defaults from breaking startup, and failed storage writes produce feedback without changing the current project or claiming success. Defaults changed in another tab update the default indicator without changing the open project's motion. JSON/HTML export settings include the derived motion-preset name alongside the authoritative numeric values.
